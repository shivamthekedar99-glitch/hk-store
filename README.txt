This folder is where your real product photos and logo file should go.

The demo site currently uses placeholder images generated by placehold.co
(a free placeholder image service) so the site works immediately without
any images of your own.

To use your own images:
1. Save your photos into this "images" folder.
   Example: images/logo.png, images/casserole.jpg, images/tawa.jpg
2. Open script.js and find the product you want to update inside the
   "ADD / EDIT PRODUCTS HERE" section.
3. Replace the "image" and "gallery" URLs with your local file path,
   for example:  image: "images/casserole.jpg"
4. For the logo, see the instructions in the main chat response.
